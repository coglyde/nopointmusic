We use a warm, paper-and-brass palette with two themes: **light** on cream (`#efeae0`) with ink text (`#181410`) and soft ink (`#5a5048`), and **dark** on warm graphite (`#282828`) with cream as the text color — never pure black, never pure white, the warmth carries across both modes. Brass (`#b08947`) and a single brand red (`#e51b18`) hold across themes, with the red reserved strictly for selection states, live indicators, and one accent dot at a time; if the red shows up on a heading or hover, it's wrong. Voice is quiet, confident, gallery-grade — "art for art," not commerce — closer to a monograph than a landing page; if a choice reads like a SaaS template or a Webflow theme, it gets cut. Typography is small with generous tracking and more whitespace than feels right: a hand-drawn wordmark, a precise mono for metadata labels, a quiet neutral sans for body (Geist is placeholder — replace it). No rounded-corner softness, no drop shadows, no autoplay audio anywhere; warmth comes from material — film grain, paper texture, brass rule lines — not from chrome. The home page is a working turntable ("the deck") that's already prototyped — the system around it should make the deck feel *more* striking by being quieter, never compete with it; the deck assets need to read correctly on both themes (the dark mode shouldn't make the brass and walnut look out of place). Stack is Tailwind CSS 4 (tokens go in `@theme inline` in `app/globals.css`, not a JS config; theme switching via `data-theme` or `prefers-color-scheme`) on Next.js 16 + React 19 App Router, with strict single-responsibility (small files, narrow hooks). Mobile is its own language, not a desktop squeeze; accessibility is parallel, not afterthought; both themes hit AA contrast; Lighthouse stays >90. Mood references: keinemusik.com, noartmusic.com, actaccordingly.nl.
